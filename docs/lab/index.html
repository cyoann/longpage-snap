How to test.

Open a fixture, tap LongPage Snap in Firefox Android, then inspect the saved result. Check the START and FINISH markers and every numbered zone. Set export options in the extension itself before each test. Return here to record Pass, Fail, or Blocked.

The lab does not invoke the extension or read its settings. This is intentional: a website cannot access Firefox's privileged extension APIs or confirm native downloads.

Interpret failures correctly

  • Known limitations (nested scrolling, horizontal overflow, moving content) are not expected to be pixel-perfect. They should finish without hanging, and limitations should remain documented.
  • Memory limits are device-dependent. Single Image may downscale or stop with a persistent error instead of exporting multiple files.
  • File validation is separate. The image validator checks dimensions, format, size and sequence by reading selected local file headers, without uploading them.
