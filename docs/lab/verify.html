Local file inspection

Verify captured images

Select downloaded images or a ZIP archive. The validator checks formats, dimensions, sizes, multipart numbering, and ZIP member CRC32 locally.

Privacy and scope.

For individual screenshots, this tool reads only the first 256 KiB of each selected image. For ZIP files, it reads the directory and calculates CRC32 in 64 KiB slices, without extracting or uploading images. Neither check proves visual completeness or native download confirmation.

1. Select images or ZIP

For a ZIP export, select the single .zip file. For individual multipart images, select all files together. Android file pickers may limit multi-selection.

No files selected.

2. Set your expectations

Copy the settings you used in LongPage Snap for individual images. ZIP inspection checks file integrity and ordered part names; dimension limits apply to individual images only. This site cannot read your extension preferences.

3. Validation results

Select files and press Inspect.

    What to check visually

    Open the image in your gallery. Confirm the fixture's START and FINISH labels, ordered zone numbers, and absence of gaps or unexpected duplicates. For multipart captures, review every part in numerical order.
