Local file inspection

Verify captured images

Select files downloaded by LongPage Snap to check their real format, pixel dimensions, file size and multipart numbering. Image data stays on your device.

Privacy and scope.

This tool reads only the first 256 KiB of each selected file to inspect its header. It does not upload, render, hash, or save screenshot content. File-type and size checks do not verify visual completeness or confirm that Firefox downloaded every part.

1. Select downloaded files

For a multipart capture, select all files together. Firefox's Android file picker might require you to select them one by one if multi-selection is unavailable.

No files selected.

2. Set your expectations

Copy the settings you used in LongPage Snap. Leave numeric limits empty if they don't apply. This site cannot read your extension preferences.

3. Validation results

Select files and press Inspect.

    What to check visually

    Open the image in your gallery. Confirm the fixture's START and FINISH labels, ordered zone numbers, and absence of gaps or unexpected duplicates. For multipart captures, review every part in numerical order.
