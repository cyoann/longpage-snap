One image or several

Single Image scales to fit safe canvas limits. Automatic and custom splitting preserve the page in ordered parts.

Choose your format

Export JPEG, PNG, or WebP. Set image quality and optional dimension or file-size limits.

Private, local processing

Captures are processed in your browser. LongPage Snap does not upload screenshots, use analytics, or track browsing.

A reproducible test environment

Use the same fixtures before every release.

The test lab contains deterministic pages for baseline stitching, sticky elements, lazy loading, growing pages, long-page memory limits, and deliberately unsupported layouts.

Run capture tests Inspect downloaded images
What the lab can and cannot verify.

Pages are controlled and hosted over HTTPS, with no external assets. The image validator reads file metadata locally. Firefox's actual download confirmation, capture permissions, visual fidelity, and device memory behavior must still be checked on the phone.

Get started

  1. Install a development build using the instructions in the GitHub repository. Public add-on store availability is not asserted here.
  2. Open the test lab in Firefox Android. Choose a fixture and capture it using LongPage Snap.
  3. Inspect the result. Use the local image validator to check file types, dimensions, sizes, and part numbering. Record the outcome in the release checklist.
